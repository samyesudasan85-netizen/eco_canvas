## 📖 Overview

**eco-canvas** is an educational image generation platform and FinOps governance dashboard designed for district school systems (300 schools scenario). It provides pedagogical tier right-sizing, auto-routing prompts to the lowest required compute fidelity to save up to 99% in cloud compute energy and costs.

### 🎯 Generation Tiers
- **Tier 1 - Eco-Outline**: 4 Steps, 512×512 resolution. Clean black & white coloring line art for kindergarten / elementary motor skills.
- **Tier 2 - Classroom Vector**: 15 Steps, 768×768 resolution. Flat vibrant educational vector graphics for instructional aids.
- **Tier 3 - District Master Baseline**: 50 Steps, 1024×1024 resolution. Photorealistic 8k official publication banner.

## 🚀 Quick Start (Local)

1. Open `index.html` directly in any web browser, or double-click `run_web.bat`.
2. To run with local python server:
   ```bash
   python -m http.server 8000
   ```
   Navigate to `http://localhost:8000`.

---

## 🌐 Deploying to GitHub Pages

1. Create a new repository named `eco-canvas` on GitHub.
2. Link remote and push:
   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/eco-canvas.git
   git push -u origin main
   ```
3. In GitHub Settings:
   - Navigate to **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, Folder: **/(root)**
   - Click **Save**
4. The live site will be deployed at `https://YOUR-USERNAME.github.io/eco-canvas/`.
